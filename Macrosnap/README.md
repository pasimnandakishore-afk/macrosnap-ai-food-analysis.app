# MacroSnap

## Project Description

MacroSnap is an AI-powered food analysis application that helps users understand the nutritional content of their meals.

## Technologies Used

- HTML
- CSS
- JavaScript
- AI / Computer Vision

## Features

- Upload or capture food images
- AI-based food recognition
- Estimated calorie information
- Macronutrient analysis
- Responsive user interface

## Prerequisites

- Modern web browser
- VS Code
- Internet connection

## Installation / Setup

Download or clone the project from GitHub.

No npm installation is required because this project does not contain a package.json file.

## How to Run

Open `index.html` in a web browser.

## Environment Variables

No environment variables are required.
